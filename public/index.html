THE LITTLE DETAILS

Good to know.

Which quality should I choose?

MP4 quality is based on the resolutions available in the original video. “Best available” keeps the highest supported resolution. MP3 offers 128, 192, 256, or 320 kbps; a higher bitrate produces a larger file and cannot improve the original audio.

How does the download server work?

Drop uses a local Python server with yt-dlp and FFmpeg. Start it on your computer, then open this website locally or connect the public page using the connection button above. The public GitHub page does not process files on its own. Your browser may ask to allow access to your local network.

Are there any limits?

The default local server accepts individual videos up to two hours and files up to 1 GB. Live streams, playlists, private videos, and protected content are not supported. YouTube may sometimes restrict downloads. Save only content you own or have permission to download.
